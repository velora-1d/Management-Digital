## 2026-07-04 - Resolve N+1 query in Dashboard Charts API
**Learning:** Found an N+1 query pattern where `Promise.all` inside a `.map()` loop was querying the `generalTransactions` table multiple times for 6 months. It's more optimal to fetch all transactions within the global timeframe in a single database query grouped by `year` and `month`, mapping the rows back to each month dynamically using `Intl.DateTimeFormat` configured with the same exact PostgreSQL `AT TIME ZONE 'Asia/Jakarta'` logic as the query to preserve precise month bucketing.
**Action:** When aggregating records across grouped date buckets like months, use a single Drizzle query with `GROUP BY` and extract operators, and build an in-memory map instead of calling the DB for each individual date period loop. Ensure that the SQL timezone casting and the JavaScript timezone formatting are explicitly aligned.
